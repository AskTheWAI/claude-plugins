# Ask The W for Claude

Ask The W is an AI-native productivity suite. This plugin connects Claude to your Ask The W projects so Claude can read a project's context and act in it when you ask.

## What it connects to

The plugin adds one remote MCP server: https://my.askthew.com/api/mcp. It runs nothing on your machine. The first time Claude uses it, you sign in to Ask The W at https://my.askthew.com and choose a project.

## What it sends and reads

- Reads the chosen project: W Card, North Star, outcomes, decisions, next moves, and Workspace files.
- Writes to that project only when you ask, for example a decision, an outcome, a move, or a file.
- Sends only what Claude passes to the tool you asked for. It never sends transcripts.

Data goes only to Ask The W at https://my.askthew.com. Privacy: https://askthew.com/privacy. Terms: https://askthew.com/terms. Support: support@askthew.com.
